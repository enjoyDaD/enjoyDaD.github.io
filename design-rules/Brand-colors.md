# Brand Colors

## Primary
브랜드 메인컬러는 50%입니다. 강조될때나 포인트컬러로 쓸때 사용합니다.  
- 50% : #2196F3
- 40% : #1C7AC7
- 20% : #13568B

## Secondary
브랜드의 서브컬러로 쓰입니다.
- mint50 : #37E686
- red50 : #F43939

## Text
텍스트 색상입니다.
- gray10 : #191919
- gray20 : #2E2E2E
- gray30 : #464646
- gray40 : #5C5C5C
- gray50 : #727272
- gray60 : #888888

## Background
배경색은 연한색으로 사용합니다.
- gray97 : #F6F6F6
- blue95 : #E9F5FE

## Line
라인은 연한색으로 사용합니다.
- gray93 : #E0E0E0
- gray95 : #EDEDED

## Badge
배지는 이 규칙으로 사용합니다.
- bluetext : #5BB0FF
- bluebackground : #E0F0FF
- minttext : #1ECA6D
- mintbackground : #E4FAEA
- redtext : #F43939
- redbackground : #FFECEC
- graytext : #888888
- graybackground : #EDEDED
